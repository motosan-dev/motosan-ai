# Implementation Plans (Archive)

These files are historical implementation plans captured during development.

- They are **not** the source of truth for current API behavior.
- Code snippets inside plans may drift from released SDK interfaces.
- For current usage, prefer:
  - Root docs: `README.md`, `AGENTS.md`, `llms.txt`
  - Rust SDK docs: `sdks/rust/README.md`, `sdks/rust/CHANGELOG.md`
  - Python SDK docs: `sdks/python/README.md`, `sdks/python/CHANGELOG.md`
  - Canonical types: `specs/types.md`

If you update a plan for historical context, keep this archive notice intact.
