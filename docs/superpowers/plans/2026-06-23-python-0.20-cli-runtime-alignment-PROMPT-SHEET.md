# Python 0.20 Alignment — Subagent Prompt Sheet

Copy-paste one block per milestone into a fresh subagent. Run milestones **in order**; each assumes the prior is merged. Plan: `docs/superpowers/plans/2026-06-23-python-0.20-cli-runtime-alignment.md`. Target release: **Python 0.13.0**.

## Standing rules (apply to every prompt)

- Every `.py`/`pyproject.toml` change goes through a **PR + CI** (never direct-to-main). One PR per milestone.
- **TDD**: write the failing test → run it red → implement → run it green → `ruff format <files>` → commit. Small commits.
- Gate before PR: `fmt` then `check-python` (ruff lint → `ruff format --check` → pytest). Must be green. Run pytest from `sdks/python` (`cd sdks/python && uv run pytest ...`).
- **Line numbers in the plan drift as milestones merge** — locate every edit by the quoted surrounding code / symbol, not the bare line number.
- **Python idioms**: async-only (no sync wrappers; callers use `asyncio.run()`); builder methods return `self`; provider logic lives ONLY in `providers/`; do NOT break the `LlmClient` Protocol.
- **HTTP-provider stream test convention** (NOT pytest-respx): `@respx.mock` decorator + `respx.post("https://mock.<prov>.com/<path>").mock(return_value=httpx.Response(200, text=<body>, headers={...}))` + the file's `provider` fixture + its `_sse(...)`/`_sse_lines(...)` helper. There is **NO** `respx_mock` fixture, **NO** `.respond()`, **NO** `_make_*()` factory. Requests are `ChatRequest(messages=[Message.user("hi")])`. Mock the **same** base_url the fixture uses. Ollama = NDJSON `text=`, no event-stream header.
- **CLI-provider test convention**: use the file's real `_FakeProc(stdout: str)` / `_FakeStdout(text: str)` (string ctor) + `_stub_subprocess(monkeypatch, fake)` which patches the **GLOBAL** `asyncio.create_subprocess_exec`. There is **NO** `_make_fake_proc` and `_FakeStdout` does **not** take `list[bytes]`. The provider-injection seam in client tests is `client._provider` — you **cannot** pass a stub to `Client(...)` (`__init__` calls `Provider(provider)` first).
- **Live CLI integration tests** are two-tier skip-guarded: binary on PATH AND an opt-in env var (mirror the existing live tests).
